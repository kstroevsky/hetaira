# Руководство по базовой русской разметке v0.1

Единица разметки — минимальный текстовый спан, достаточный для наблюдения. Одно высказывание может иметь несколько диалоговых актов.

## Обязательные действия разметчика

1. Выделить точный спан в конкретной ревизии сообщения.
2. Указать говорящего и, для позиции, явную цель.
3. Использовать `abstain`, если цель или достаточный спан не определяются.
4. Не выводить личностные черты, влияние, власть или причинность.
5. Отделять `ACKNOWLEDGE` от `AGREE`: понимание не означает принятие позиции.
6. Отделять `UNCERTAIN` от негативной тональности: эпистемическая осторожность не является эмоцией.

Основные определения и примеры находятся в `backend/src/prometheus_observatory/codebooks/ru/foundational-v0.1.yaml`. Изменение определения создаёт новую версию codebook и не перезаписывает прежние аннотации.
