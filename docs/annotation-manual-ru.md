# Руководство по базовой русской разметке v0.1

Единица разметки — минимальный текстовый спан, достаточный для наблюдения. Одно высказывание может иметь несколько диалоговых актов.

## Обязательные действия разметчика

1. Выделить точный спан в конкретной ревизии сообщения.
2. Указать говорящего и, для позиции, явную цель.
3. Использовать `abstain`, если цель или достаточный спан не определяются.
4. Не выводить личностные черты, влияние, власть или причинность.
5. Отделять `ACKNOWLEDGE` от `AGREE`: понимание не означает принятие позиции.
6. Отделять `UNCERTAIN` от негативной тональности: эпистемическая осторожность не является эмоцией.

Основные определения и примеры находятся в `backend/src/prometheus_observatory/codebooks/ru/foundational-v0.1.yaml`. Изменение определения создаёт новую версию codebook и не перезаписывает прежние аннотации.

## Процесс `gold-ru-v0`

1. Создать пилотную выборку в разделе **Разметка** или командой `scripts/gold_ru_pilot.py create`.
2. Размечать только точный спан выбранной ревизии. Система сохраняет Unicode-offset и хэш текста.
3. Проверяющий независимо выбирает `confirmed`, `disputed` или `rejected`. Проверка создаёт отдельную append-only запись и не переписывает исходную аннотацию.
4. При разногласии adjudicator создаёт заменяющую аннотацию. Исходная остаётся доступной и получает ссылку `superseded_by`.
5. Набор можно заморозить только после подтверждения каждой единицы. Заморозка фиксирует snapshot, codebook artifact, split, исходные text hashes и итоговые аннотации единым manifest SHA-256.
6. Train/development/test назначаются по целому эпизоду или разговору. Сообщения одной группы не могут оказаться в разных split.

Пилот предназначен для проверки руководства на 150–250 единицах. Научный `gold-ru-v1` расширяется до 1 200 единиц только после разбора ошибок пилота; 30% выборки размечаются независимо двумя людьми.
