# Requirements-to-evidence matrix

| Construct | Required primitives | Minimum controls | Foundation status |
| --- | --- | --- | --- |
| Semantic evolution | concept mentions, contextual uses, time, proposition links | frequency, participant, topic | interface ready |
| Roles | dialogue/social acts, grounding, network position, episode | episode goal, activity | basic profiles next |
| Agreement | holder→target stance observations | uncertainty, target identity | implemented seam |
| Reciprocity | ordered response events, sender, receiver, latency | activity, opportunity | basic explicit replies implemented |
| Coordination | directional lexical/style features | baseline rate, topic, act type | plugin seam ready |
| Knowledge flow | proposition/concept origin, exposure, acknowledgement, reuse | opportunity, popularity | ontology ready |
| Relationship dynamics | longitudinal dyadic measurements | activity, topic, group composition | ontology ready |
| Influence | agenda, semantic, epistemic, persuasion, behavior, brokerage | all above plus history | blocked pending validation |
| Power | formal role, attention, agenda control, uptake, asymmetry | activity and opportunity | blocked pending validation |
| Persuasion | stance before/exposure/after and competing exposures | susceptibility, topic, external evidence | blocked pending validation |
| Coalitions | position graph and interaction graph separately | time window and uncertainty | blocked pending validation |
| Conversation health | responsivity, grounding, repair, participation, goal progress | declared conversation goal | blocked pending validation |
| Forecasting | explicit outcome and chronological state | forward-time split | predictive phase |
| Pivotal moment | calibrated outcome forecaster and plausible replies | simulator quality | predictive phase |
